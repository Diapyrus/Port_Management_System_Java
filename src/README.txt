Small Overview

intro
This project is a Java-based simulation of a ship and port management system. The system is designed to manage ships, ports, and various types of containers, simulating their interactions and movements. The app utilizes Java Swing for the graphical user interface (GUI) to make the simulation user-friendly more interactive and visually appealing. It showcases data handling, dynamic object management, GUI development, and a somewhat robust error handling, providing a valuable tool for simulating real-world scenarios in marinetime logistics


features / achievements
    Data Loading: Successfully implemented the functionality to load ports, ships, and containers from txt files.
    Simulation Scenarios: Developed two distinct simulation scenarios to demonstrate different operational strategies.
    Dynamic Container Management: Implemented different types of containers with specific fuel consumption calculatins.
    User Interface: Created a user-friendly interface using Java Swing, including buttons for resetting the system, running simulations, and showing statuses.
    Error Handling: Added error handling to manage and debug file loading issues and invalid data entries.
    Code Documentation: Thoroughly commented code to ensure readability and ease of maintenance.


usage
    txt files (ports.txt, ships.txt, containers.txt) with the correct data format needed.
    Compile and run the Java application.
    Use the GUI to load data, run simulations, and view statuses.
